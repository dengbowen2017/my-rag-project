# My RAG Project

This project will be developed entirely through vibe coding, with Codex handling all code implementation under my guidance.

The project will evolve incrementally, starting with a simple LLM API call and gradually progressing toward a fully functional agentic RAG system.

All `AGENTS.md` files will be preserved in this repository to document how I guide Codex through each stage of development and how the system evolves over time.

The goal is not only to build an agentic RAG system, but also to explore how AI-assisted development can be used to incrementally design and implement a complex software system.
